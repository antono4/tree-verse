# 🌳 Tree Verse

Repository untuk penghijauan (green/github activity) secara otomatis.

## 📌 Deskripsi

Repository ini menggunakan GitHub Actions untuk melakukan "penghijauan" secara otomatis dengan meng-update timestamp README setiap beberapa jam.

## ⚙️ Workflows

| Workflow | Jadwal | Fungsi |
|----------|--------|--------|
| C1 | Setiap 4 jam | Update timestamp README |
| C2 | Setiap 6 jam | Update timestamp README |

## 📝 Catatan

- Timestamp menggunakan zona waktu Indonesia (WIB / UTC+7)
- Setiap commit signed dengan GPG key
